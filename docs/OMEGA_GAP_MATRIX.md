**The smallest vertical slice (contract §20.4), chosen:**
1. A typed candidate: an acquisition program of `science.acquire`, Genesis's own (B20_R129's searches).
2. Deterministic, metered execution; the independent checker `causal.admg.score` against the planted truth.
3. Exact archive in the vault, with lineage (search, generation, parents) and status.
4. A capability edge from B20_R130's verified global interpretation.
5. The trigger reactivates the dormant programs whose failure reason is "interpretation-limited".
6. The measurable comparison against fresh search at matched compute, random retrieval and a null trigger (B20_R131).

It can fail honestly: if reactivated programs are no better than fresh search, the cascade is recorded as adding no
value.
