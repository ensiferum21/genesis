## What was built

`src/genesis/invention/quotients.py`. A host's representation is a partition q into K blocks
plus a pattern Q on the blocks. Both are optimised per host:
- the exact best transitive-triple-free pattern for the partition, by branch and bound,
  cross-checked against brute force in the tests;
- vertex moves under that pattern;
- greedy completion under the domain checker.

A relational decoder is the special case where Q is fixed in advance. What is new is that Q is
chosen per host and K can go up to 6.

**Lean** (`QTDefs`, package in the evidence). One parametric theorem covers every q, Q and H:
- `GT.TriangleFree Q → GT.TriangleFree (QT.lift q Q H)`;
- `QT.lift q Q H ⊆ H`.

Both are CHECKED with builder-written recipes, which are named in the receipts.
