# Genesis Batch 1 — adversarial promotion and evidence-tree audit (DEV only)

Date: 2026-10-09 SGT. This is a local adversarial review, **not** independent custody or an external security audit.

## GEN-AUD-015 — self-attested evidence could make local preflight claim promotion permission (CRITICAL)

The original `scripts/promotion_preflight.py` could return `promotion_allowed_by_this_preflight=True` with `status=PREFLIGHT_PASS_PENDING_INDEPENDENT_REPLICATION` for wholly fabricated local evidence: a fake audit marked PASS, 20/20 invented job counts, 300 unsubstantiated task count, a one-file raw evidence manifest and an Ed25519 signature from a key generated by the research process itself. The verifier checked signature validity but could not establish who controlled the key, the evaluator or the independent audit. Before patch, the exact local negative test returned `True` with no reasons. **This is not evidence that the full release system promoted anything; it is a misleading authorization surface.**

Mitigation: preflight now returns `prerequisites_present=True` for a locally consistent synthetic package but **never** `promotion_allowed_by_this_preflight=True`. Its CLI exits nonzero until a separately controlled release authority exists. A real independent custodian/key pin and independent evidence review remain outstanding. No local self-attestation is promoted.

## GEN-AUD-016 — untracked symlink omitted from evidence manifest (HIGH)

The old `build_manifest()` silently skipped symlink files. After creating a valid evidence manifest, inserting an untracked symlink named `untracked-private.json` produced an empty `verify_manifest()` issue list. This could conceal links to protected data from the evidence-tree inventory; it does not prove a sealed-data leak occurred. The patched manifest code fails closed on symlinks and special files, including a symlinked manifest, and verifies the expected schema.

## Tests and limitations

The four new negative tests cover (1) locally self-signed fake promotion evidence, (2) an extra symlink, (3) a symlink hidden under an ignored cache directory and (4) a symlinked manifest. All four pass after the repair. Full integrated regression: **211 tests, 210 passed, 1 skipped**. No real Lean, independent external evaluator, sealed tasks, or scientific confirmation were performed. All earlier audit findings and historical missing 11/20 raw jobs remain preserved; Batch 1 is still FAILED_REPAIR_REQUIRED and the accepted base is unchanged. Independent re-audit of this patch is still required.
