# B14 internal red team, round 3 (commit `439b764`)

A third fresh agent (same operator; not external independence) attacked the tree
after the round-2 repairs. Scripts (`r*_*.py`, `_r3.py`) and their original
outputs (`logs_before_fix/`) are unchanged. On the repaired tree
(`logs_after_fix/`) every script is blocked, most at an earlier and stricter
check; each attack is re-expressed against current schemas in
`tests_genesis/test_redteam_b14_round3.py` (F9 in
`tests_certificates/test_certificate_custody.py`).

| ID | Severity | Finding | Repair |

| F3 | HIGH | OPTIMALITY_CHECKED for a false statement with a genuine certificate | a mathematical claim's statement is generated by the kernel from the stored problem (domain, host, hash, value, lower bound or optimum); free text is refused |
| F4 | HIGH | WITNESS_VALID for false statements | every math level from WITNESS_VALID up requires a problem; witness, bound state and problem must agree; OPTIMALITY_CHECKED requires an optimum claim |
